# C1 · Code Crunch Convos — Syllabus

**Format:** 15 weeks · ~36 hrs/week intensive (or 30 weeks at ~18 hrs/week part-time) · absolute beginner → portfolio-ready Python engineer

The flagship Python bootcamp of the Code Crunch Club, and the on-ramp to C2, C13, and C14.

**Prerequisites.** None beyond a computer, a willingness to read documentation, and the weekly hours. No prior programming experience is assumed — Week 1 starts at "I've never written code."

**Assessment is honor-based.** There are no proctors and no grades. Every quiz, homework set, and mini-project is self-checked against the rubric in its week folder; the credential is the public work in your GitHub repo, not a certificate. You advance when your own work convinces you — and anyone who reads your repo — that you have it.

---

## Program at a glance

| Phase | Weeks | Outcome |
|-------|-------|---------|
| **Phase 1 — Python fundamentals** | 01 – 04 | Syntax, control flow, functions and modules |
| **Phase 2 — Structures & objects** | 05 – 07 | Data structures, file I/O, object-oriented design |
| **Phase 3 — Real-world Python** | 08 – 12 | APIs, web apps, databases, testing, automation |
| **Phase 4 — Data, ML & capstone** | 13 – 15 | pandas, a first ML model, portfolio capstone |

## Weekly breakdown

Each week ends in a shippable mini-project — one public artifact on GitHub.

| Week | Topic | Mini-project |
|------|-------|--------------|
| 01 | Python Foundations & Dev Environment | "Hello, You" personal greeter |
| 02 | Variables, Data Types & Operators | Unit converter CLI |
| 03 | Control Flow — Conditionals & Loops | Number-guessing game |
| 04 | Functions, Modules & Scope | Personal finance calculator |
| 05 | Data Structures & Comprehensions | Contact book manager |
| 06 | File I/O & Exception Handling | Log file analyzer |
| 07 | Object-Oriented Programming | Library management system |
| 08 | APIs, JSON & HTTP | Weather dashboard CLI |
| 09 | Web Development with Flask | Personal blog web app |
| 10 | Databases & SQL with Python | Task tracker with SQLite |
| 11 | Testing, Debugging & Code Quality | Tested utility library |
| 12 | Automation & Scripting | File organizer bot |
| 13 | Data Analysis with pandas | Real-world dataset analysis |
| 14 | Intro to AI/ML with scikit-learn | Spam classifier |
| 15 | Capstone Project | Your portfolio centerpiece |
