# Week 1 Exercises

Short, focused coding tasks that drill the concepts from the Week 1
lectures. Aim to finish each one in a single sitting. If you get stuck,
re-read the relevant lecture and try again — the goal is comfort, not
speed.

## How to Run an Exercise

Each exercise below is a page, not a program. The page gives you the
brief, a starter you copy into your own file, the exact output to expect,
and the errors to watch for. You create the `.py` file yourself, in your
own practice repo, and run it from a terminal.

1. Open a terminal.
2. Activate your Week 1 virtual environment (see Lecture 2).
3. Open the exercise page and copy its starter into a new file named
   after the exercise — for exercise 1 that is
   `exercise-01-hello-world.py`.
4. Fill in the `TODO` markers, save, and run it from your `exercises/`
   folder:

   ```bash
   python exercise-01-hello-world.py
   ```

Exercises 2 and 3 also spend time at the `>>>` prompt. Those pages show
the REPL session to work through before you write the file.

## Checking Your Work

There is no automated grader for Week 1. For each exercise, verify
yourself that:

- The script runs without errors.
- The printed output matches the page's "Expected output" section.
- Any answers you paste as comments are correct.
- Every box in the page's acceptance checklist is honestly ticked.

When all three are done, move on to
[the Week 1 challenges](../challenges/README.md).
