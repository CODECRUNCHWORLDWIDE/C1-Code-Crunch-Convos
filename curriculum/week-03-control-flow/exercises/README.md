# Week 3 — Exercises

Five short exercises to drill conditionals and loops. Each one is a page:
the brief, a starter you copy into your own `.py` file, the exact output to
aim for, and the bugs to expect on the way. Read the page, create the file
in your practice repo, fill in the marked `TODO` sections, and run it from
your terminal:

```bash
python exercise-01-fizzbuzz.py
```

You should be able to finish each exercise in **15–30 minutes**. If you
get stuck for more than that, re-read the matching section in the
lecture notes and try again. Working code beats elegant code at this
stage — get it running first, polish later.

## The Exercises

| # | Exercise | What you will practise | Difficulty | Est. time |
|---|----------|------------------------|-----------:|----------:|
| 1 | [exercise-01-fizzbuzz.md](./exercise-01-fizzbuzz.md) | `for`, `range`, `if`/`elif`/`else`, modulo | Beginner | 15 min |
| 2 | [exercise-02-sum-evens.md](./exercise-02-sum-evens.md) | Accumulator pattern, `range` with step | Beginner | 15 min |
| 3 | [exercise-03-password-checker.md](./exercise-03-password-checker.md) | `while True`, `break`, `any()`, guard clauses | Easy | 25 min |
| 4 | [exercise-04-multiplication-table.md](./exercise-04-multiplication-table.md) | Nested `for` loops, `print` formatting | Easy | 20 min |
| 5 | [exercise-05-find-prime.md](./exercise-05-find-prime.md) | `for` + `else`, early `return`/`break` | Medium | 30 min |

## Suggested order

Do them in order. Each one builds on a pattern from the previous
exercise, and 1–2 are warm-ups for the harder 3–5.

## How to submit

If you are tracking your work in Git (highly recommended — see Week 1),
commit each exercise as you finish it:

```bash
git add exercises/exercise-01-fizzbuzz.py
git commit -m "Week 3: complete FizzBuzz exercise"
```
