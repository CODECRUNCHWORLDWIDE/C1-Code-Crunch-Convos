# Week 14 — Exercises

Five short, focused tasks. Each one targets a specific concept from the
lectures. Work through them in order; later ones reuse ideas from earlier ones.

Each exercise is a page, not a file you download. The page gives you the brief,
a starter with `TODO` markers, the exact output to aim for, and the errors you
are most likely to hit. You copy the starter into your own `.py` file in your
practice repo, fill in the gaps, and run it.

## Setup

```bash
pip install scikit-learn pandas numpy matplotlib
```

Create a file per exercise, keeping the same name as the page:

```bash
python exercises/exercise-01-linear-regression.py
```

Every exercise is fully self-contained. The data is either written inline in
the starter or generated by `sklearn.datasets` — no downloads, no API keys,
no network.

## How to work through these

1. **Read the whole page before you type anything.** Predict the output. Write
   your prediction down.
2. **Type the starter out rather than pasting it,** at least for the first two.
   The sklearn API is muscle memory, and muscle memory does not come from the
   clipboard.
3. **Run it.** Compare reality with your prediction. The gap is the learning.
4. **Break things.** Change `random_state`. Drop a feature. Swap the model.
   Notice what moves and what does not.
5. **Write down one observation per exercise.** Even if it is just "accuracy
   jumped when I scaled".

There is no automated grader. The point is fluency with the workflow, not a
leaderboard. Each page ends with an acceptance checklist — that is your grader.

## A rule for this week

**Pin every seed.** Anywhere scikit-learn accepts `random_state` — the split,
the model, a data generator — pass it. Without it, two runs of the same script
produce different numbers, and you will not be able to tell whether a change
you made helped or whether the dice simply rolled differently. Every exercise
below enforces this, and Exercise 3 exists entirely to show you what happens
when you skip it.

## Stuck?

- `ValueError: Expected 2D array` — you passed a Series where a DataFrame is
  needed. Use `df[["col"]]`, not `df["col"]`.
- `ConvergenceWarning` — the solver ran out of iterations. Add `max_iter=1000`,
  and if it still warns, scale your features (Exercise 4).
- `UserWarning: X does not have valid feature names` — you predicted with a
  bare list or array on a model that was fitted with a DataFrame. Wrap your new
  rows in a DataFrame with the same column names.
- Imports failing — check that your virtual environment is active and has
  `scikit-learn`, `pandas`, and `numpy` installed.
